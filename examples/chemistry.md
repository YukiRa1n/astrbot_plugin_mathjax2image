# 化学 · 反应、离子与平衡

## 化学平衡

$$\ce{N2(g) + 3H2(g) <=> 2NH3(g)}$$

$$K_p=\frac{(p_{\ce{NH3}}/p^\circ)^2}
{(p_{\ce{N2}}/p^\circ)(p_{\ce{H2}}/p^\circ)^3}$$

## 氧化还原

$$\ce{Zn(s) + Cu^{2+}(aq) -> Zn^{2+}(aq) + Cu(s)}$$

$$\begin{aligned}
\text{氧化：}\quad&\ce{Zn -> Zn^{2+} + 2e^-}\\[5pt]
\text{还原：}\quad&\ce{Cu^{2+} + 2e^- -> Cu}
\end{aligned}$$
