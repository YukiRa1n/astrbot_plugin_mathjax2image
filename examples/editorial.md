# 从变化中寻找规律

用一个函数、一条公式和几行代码，理解导数如何描述变化。

## 在一点附近，看见变化

把镜头移到曲线的一小段，弯曲的轨迹会逐渐接近一条直线。**导数就是这条直线的斜率**：它告诉我们，输入增加一点时，输出会怎样改变。

$$
f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

对于 $f(x)=x^2$，有 $f'(x)=2x$。在 $x=1$ 处，切线斜率为 $2$。

> 公式描述精确的关系，直觉帮助我们理解关系。

## 把符号与含义对应起来

| 表达 | 含义 | 例子 |
| --- | --- | --- |
| $f(x)$ | 某个位置的函数值 | $f(1)=1$ |
| $f'(x)$ | 某个位置的变化速度 | $f'(1)=2$ |
| $\int_a^b f(x)\,dx$ | 一个区间内的累积量 | $\int_0^1 x^2\,dx=\frac13$ |

### 用代码验证

中心差分用左右两侧的函数值估计导数。下面的结果接近解析值 $2$。

```python
def derivative(f, x, h=1e-5):
    left = f(x - h)
    right = f(x + h)
    return (right - left) / (2 * h)

print(derivative(lambda x: x**2, 1))
```

选择步长时，需要平衡两类误差：

- 步长过大，曲线的弯曲会影响直线近似。
- 步长过小，浮点运算的舍入误差会被放大。
